目标：用最少最短的步骤，搭出一个能跑起来的最小可用知识库。不追求完美，不搞花活，先让它转起来，后面再慢慢炼。

## 1、准备工作

需要三个东西：

- 一台能上网的电脑
- Obsidian 笔记管理软件 + 官方插件 Obsidian Web Clipper。前者是知识库载体，后者用来一键保存浏览的资料。
- AI 工具。可以是 Claude Code、OpenAI 的 Codex CLI、Google 的 Gemini CLI 等。

Obsidian 官网：`https://obsidian.md/`

下载后打开 Obsidian，创建仓库作为知识库。名字按自己喜欢（如 MyBrain、MyKnowledgeBase），位置建议放在清晰明了的目录，也方便 AI 工具访问，如 `D:\MyBrain`。

接着安装 Obsidian Web Clipper，在浏览器应用商店搜索并下载。

## 2、搭建知识库最小文件夹结构

打开 Claude Code，告诉它将仓库目录作为知识库，并按如下结构创建架构：

```
MyBrain/
├── Inbox/               ← 所有新资料先扔这里，不用管分类
├── Wiki/                ← 知识库的大脑：整理、归档、索引全在这里
│   ├── Index.md         ← 全局索引，AI 自动维护的知识地图
│   ├── Log.md           ← 操作日志，每次整理都记录在案
│   └── AI/              ← 按主题分类的归档文件夹（AI 自动创建）
│       └── 工具/
│       └── 职场/
│       └── ...
├── Output/              ← 输出层：成品文章、项目文件、问答沉淀
└── CLAUDE.md            ← 给 AI 的指令文件
```

三个文件夹，对应三层架构：

- `Inbox`：入口，所有东西不经思考直接丢进去，降低「存」的心理门槛
- `Wiki`：处理层，AI 把 Inbox 里的东西消化后按主题归档。`Index.md` 是全局索引（AI 每次整理自动更新），`Log.md` 是操作日志
- `Output`：出口，最终成品在这里产出

## 3、写好你的第一份 CLAUDE.md 指令文件

CLAUDE.md 是一份纯文本说明书，让 AI 每次进入知识库时都带着上下文——知道文件夹怎么组织、工作流程是什么、该遵守什么规则。随着使用会不断进化。

最小可用配置示例：

```markdown
# 知识库操作指南

## 身份
你是我的个人知识库助手。你的工作是帮我管理、整理、使用这个知识库中的内容。

## 知识库结构
- `Inbox/`：收件箱。所有新资料的入口，未经整理的原始内容都在这里。
- `Wiki/`：知识库核心。整理归档后的一切都在这里，包含：
  - `Wiki/Index.md`：全局索引。每次整理后必须更新。
  - `Wiki/Log.md`：操作日志。每次执行整理任务追加一条记录（日期 + 处理了哪些文件 + 归入了哪些分类）。
  - `Wiki/<分类名>/`：按主题分类的子文件夹，分类由你根据内容自动判断和创建。
- `Output/`：输出层。最终的文章、报告、项目成品存放在这里。

## 核心工作流程

### 任务一：整理 Inbox
当我说"整理 inbox"时，你需要：
1. 读取 `Inbox/` 中所有文件
2. 理解每篇内容的主题
3. 在 `Wiki/` 下找到或创建合适的分类子文件夹
4. 将文件移动到对应的子文件夹
5. 更新 `Wiki/Index.md`（标题、分类、关键概念、文件路径）
6. 在 `Wiki/Log.md` 末尾追加本次操作记录
7. 完成后告诉我处理了多少篇，分别归入了哪些分类

### 任务二：查询知识库
1. 先查阅 `Wiki/Index.md` 定位相关文件
2. 读取相关文件的内容
3. 给我一份结构化的回答，注明信息来源（哪个文件）

### 任务三：辅助写作
1. 先通过 Index.md 和 Wiki 中的资料查找相关素材
2. 基于素材和我的要求生成草稿
3. 将成品保存到 `Output/` 对应的子文件夹

## 规则
- 移动或修改文件前，先告诉我你打算做什么，等我确认
- 不要删除任何原始文件，只做移动和复制
- 所有新建文件使用 Markdown 格式
- 文件命名使用中文，简洁明了
- 每次整理后必须更新 Index.md 和 Log.md
- 如果不确定某篇资料该归到哪个分类，就问我
```

可以继续追加的规则示例：

```
文件夹命名统一格式：英文在前，对应中文在后，用连字符连接
示例：AI-AI知识库、Business-商业诊断、Tools-工具、Models-模型
纯英文产品名保持原样，不强制加中文（如 Claude、NotebookLM）
不使用数字前缀（顶层主文件夹除外）
```

## 4、跑通一个完整流程：存 → 整理 → 用

**存**：打开浏览器的 Obsidian Web Clipper 插件 → 点击 new template → 在 Note location 填入知识库中负责保存未整理资料的文件夹名称（本教程是 `inbox`）。保证文件夹名称一致，即可一键保存到正确位置。

**整理**：给 AI 下指令"整理 inbox"，无论多少资料，AI 都会按照 CLAUDE.md 中的规则分门别类，整理完后自动清空 inbox 中的内容。

**用**：给 AI 下一句指令，让它搜索所有相关笔记，形成草稿或文章供参考。
